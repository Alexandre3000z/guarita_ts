## Descrição

Projeto feito para criar conexões com dispostivos guarita e recolher informações através de app NICE


## Instalação

* Node.js
* Faça o clone do projeto
* Execute o comando ```npm install```

## Rodar o projeto

* ```npm run dev```ou ```npm run start``` - Executa a aplicação com ts-node e roda um servidor em http://localhost:9000 para testar o projeto.

* ```npm run front``` - Executa a aplicação com ts-node e roda um front-end em http://localhost:9001 para testar o projeto.
